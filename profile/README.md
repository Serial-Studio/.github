[Serial Studio](https://serial-studio.com) turns data from your hardware into a live
dashboard. Connect an Arduino, ESP32, STM32, Raspberry Pi, Teensy, or anything else that
speaks serial, Bluetooth, a network protocol, or an industrial bus. Describe the data
format once in a project file, and Serial Studio draws the plots, gauges, maps, and 3D
views around it. Send commands back with buttons, sliders, and knobs. Record a session,
replay it, export it as a PDF.

It replaces the stack of separate tools this work usually requires: a serial monitor and
serial plotter for Arduino and ESP32 development, a real-time telemetry dashboard, a data
logger that writes CSV or SQLite, and a Modbus, CAN bus, or MQTT monitor for industrial and
IoT systems. It runs on Windows, macOS, Linux, and Raspberry Pi.

People use it in rocketry, drones, motorsport, robotics, environmental monitoring,
industrial automation, and university labs.

### Get it

- [Download the latest release](https://github.com/Serial-Studio/Serial-Studio/releases/latest)
  for Windows, macOS, Linux, and ARM64.
- [Flathub](https://flathub.org/apps/com.serial_studio.Serial-Studio), or
  `brew install --cask serial-studio` on macOS.
- [Build from source](https://github.com/Serial-Studio/Serial-Studio) the GPLv3 build.

The application is dual-licensed. The GPLv3 build is free and covers serial, Bluetooth LE,
TCP/UDP, and 17 widgets. [Pro](https://serial-studio.com) adds MQTT, Modbus, CAN bus, USB,
HID, audio, 3D and XY plots, output widgets, MDF4 and session recording, and the AI
assistant.
