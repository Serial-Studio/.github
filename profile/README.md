[Serial Studio](https://serial-studio.com) turns data from your hardware into a live dashboard. Describe your data format once in a project file, and it builds the plots, gauges, maps, and 3D views around it. [Download a release](https://github.com/Serial-Studio/Serial-Studio/releases/latest) for Windows, macOS, Linux, and Raspberry Pi, install it from [Flathub](https://flathub.org/apps/com.serial_studio.Serial-Studio), or [build it from source](https://github.com/Serial-Studio/Serial-Studio).

The goal is one program in place of the usual pile of serial monitor, plotter, telemetry dashboard, CSV logger, and bus sniffer. Point it at an Arduino, an ESP32, an STM32, or anything else that speaks serial, Bluetooth, a network protocol, or an industrial bus. Send commands back, record a session, replay it, export it as a PDF. It is used in rocketry, drones, motorsport, robotics, industrial automation, and university labs.

Serial Studio is developed in the open, and [contributions](https://github.com/Serial-Studio/Serial-Studio/blob/master/CONTRIBUTING.md) to both the GPL code and the commercial modules are welcome. The [Help Center](https://serial-studio.com/help) covers setup and troubleshooting, [discussions](https://github.com/Serial-Studio/Serial-Studio/discussions) are for questions and project showcases, and [issues](https://github.com/Serial-Studio/Serial-Studio/issues) are for bugs and feature requests.

Maintaining an application of this size is no small task, and it is done by one person. The GPLv3 build is free and covers serial, Bluetooth LE, TCP/UDP, and 17 widgets. [Serial Studio Pro](https://serial-studio.com) adds MQTT, Modbus, CAN bus, USB, HID, audio, 3D and XY plots, output widgets, MDF4 and database recording, and the AI assistant. Buying a Pro license is what funds the work, and [donations](https://www.paypal.com/donate?hosted_button_id=XN68J47QJKYDE) help too.
