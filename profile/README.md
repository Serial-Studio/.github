[Serial Studio](https://serial-studio.com) turns data from your hardware into a live dashboard. Point it at an Arduino, an ESP32, an STM32, a Raspberry Pi, or anything else that speaks serial, Bluetooth, a network protocol, or an industrial bus; describe the data format once in a project file, and Serial Studio builds the plots, gauges, maps, and 3D views around it. Send commands back, record a session, replay it, export it as a PDF. One program in place of the usual pile: serial monitor, plotter, telemetry dashboard, CSV logger, bus sniffer.

It runs on Windows, macOS, Linux, and Raspberry Pi, and is used in rocketry, drones, motorsport, robotics, industrial automation, and university labs. [Download a release](https://github.com/Serial-Studio/Serial-Studio/releases/latest), install it from [Flathub](https://flathub.org/apps/com.serial_studio.Serial-Studio), or [build it from source](https://github.com/Serial-Studio/Serial-Studio). The GPLv3 build is free and covers serial, Bluetooth LE, TCP/UDP, and 17 widgets; [Serial Studio Pro](https://serial-studio.com) adds MQTT, Modbus, CAN bus, USB, HID, audio, 3D and XY plots, output widgets, MDF4 and database recording, and the AI assistant.

The [Help Center](https://serial-studio.com/help) covers setup and troubleshooting, [discussions](https://github.com/Serial-Studio/Serial-Studio/discussions) are for questions and project showcases, and [issues](https://github.com/Serial-Studio/Serial-Studio/issues) are for bugs and feature requests. Contributions to the GPL code and to the commercial modules are both welcome; see [CONTRIBUTING.md](https://github.com/Serial-Studio/Serial-Studio/blob/master/CONTRIBUTING.md). Serial Studio is built and maintained by one person, so Pro licenses and [donations](https://www.paypal.com/donate?hosted_button_id=XN68J47QJKYDE) are what fund the work.
