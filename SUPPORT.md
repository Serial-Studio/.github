# Support

## Using Serial Studio

- **[Help center](https://serial-studio.com/help)** — setup guides, troubleshooting, FAQs,
  and the full manual. Start here.
- **[Discussions](https://github.com/Serial-Studio/Serial-Studio/discussions)** — questions,
  project showcases, and ideas that are still taking shape.
- **[Examples](https://github.com/Serial-Studio/Serial-Studio/tree/master/examples)** —
  working projects with device firmware, from Arduino CSV output to MAVLink and Modbus.

## Something is broken

Open an [issue](https://github.com/Serial-Studio/Serial-Studio/issues) with the bug report
template. Include your OS, the version and edition you are running, your connection type,
and steps to reproduce. Attach the `.ssproj` project file and console output when they are
relevant.

Please do not report security vulnerabilities as public issues. See
[SECURITY.md](SECURITY.md).

## Commercial licensing and Pro support

Pro licenses include priority support by email. For licensing questions, invoices, volume
or site licenses, and activation problems, see [serial-studio.com](https://serial-studio.com)
or write to alex@serial-studio.com.

## Response times

Serial Studio is maintained by one person. Community issues and discussions are answered as
time allows; Pro support email is answered first.
